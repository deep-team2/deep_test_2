## 1. 멘티 결과에서 발견한 문제점

### 1) C라인의 이상값 처리 오류 (행 누락)
* **내용:** 이상값을 수정하지 않고 행 자체를 삭제함 (완전 중복만 제거한 원본과 비교했을 때 C라인의 행이 60행에서 57행으로 3행 감소).
* **영향:** C라인의 데이터 비율이 실제보다 작아지고, 라인별 평균이나 이후 모델 학습 결과가 원본과 다른 방향으로 치우칠 수 있음.

### 2) 중복 검사 기록 처리 누락
* **내용:** 같은 검사 기록을 서로 다른 행으로 남겨둠. 검사일시, 생산라인, 설비번호가 같은데 센서값이 0.03만 다른 기록이 존재함.
* **영향:** 컴퓨터는 완전히 같은 행이 아니므로 중복으로 판단하지 않지만, 실제로는 같은 시간에 같은 설비를 검사한 기록이므로 두 행을 모두 사용하면 특정 검사가 두 번 반영되어 평균과 행 수가 왜곡됨.

### 3) 통합 기준 이상값 판단
* **내용:** 모든 생산라인을 하나로 합쳐 온도 이상값을 판단함.
* **영향:** A라인의 평균 온도는 73.35도이고 C라인의 평균 온도는 94.57도이므로, 73.5도는 A라인에서는 정상 범위이지만 C라인에서는 이상값이 될 수 있음. 전체 평균과 표준편차만 사용하면 라인별 온도 차이가 사라져 실제 이상값을 놓치거나 정상값을 이상값으로 잘못 처리하게 됨.

### 4) 결측값 대체 기준 오류
* **내용:** 온도 결측값을 해당 생산라인의 평균이 아닌 전체 데이터의 평균으로 채움.
* **영향:** 같은 A라인 기록의 정규화 온도가 멘토 결과에서는 0.1111인데 멘티 결과에서는 0.5363으로 나타났고, 멘티 결과의 A라인 평균 온도도 원본보다 0.55도 높아짐. 생산라인별 온도 특성이 약해지고 정규화 결과가 달라져 모델이 잘못된 패턴을 학습할 수 있음.

## 2. 고치는 과정에서 조심한 점

### 1) 정제 파이프라인 순서 준수
* 먼저 완전 중복을 제거한 뒤, 업무상 같은 검사로 볼 수 있는 키 중복을 확인하고, 그다음 이상값을 처리한 후 결측값을 채우는 순서로 진행함. 중복값이나 이상값이 남아 있는 상태에서 평균과 중앙값을 계산하면 대치 기준 자체가 왜곡되기 때문임.

### 2) 반복적(Iterative) 이상값 재탐지
* 이상값은 한 번 처리하고 끝내지 않고 다시 계산하여 재탐지함. 매우 큰 압력 이상값 하나가 표준편차를 크게 만들면 그보다 작은 이상값이 정상 범위처럼 가려질 수 있으므로, 1차 이상값을 해당 라인의 중앙값으로 바꾼 뒤 표준편차와 Z-score를 다시 계산함. 2차 처리 후에도 3차 탐지 결과를 확인하여 더 남은 이상값이 없는지 검증함.

### 3) 변수 특성별 맞춤형 결측값 처리
* 온도, 진동, 압력의 결측값을 모두 같은 방법으로 채우지 않음. 
  * **온도:** 생산라인별 평균 사용
  * **진동 및 압력:** 이상값의 영향을 더 받을 수 있으므로 생산라인별 중앙값 사용
* 또한 진동은 문자열이 섞여 있을 가능성이 있어 먼저 숫자형으로 변환하고 변환할 수 없는 값은 결측값으로 처리함.

### 4) 데이터 누수(Data Leakage) 방지
* 정규화 기준은 전체 데이터가 아니라 학습 데이터에서만 구함. 검증 데이터와 테스트 데이터의 최솟값·최댓값까지 미리 사용하면 평가에 사용할 정보가 학습 과정에 들어가는 데이터 누수가 발생하기 때문임. 학습 데이터에서 구한 기준은 `스케일링기준.csv`에 따로 저장하여 새 배치에도 같은 기준을 다시 적용함.

## 3. 판단이 필요했던 지점

* **센서값이 미세하게 다른 중복 행 처리:** 같은 검사일시, 생산라인, 설비번호를 가진 두 행의 센서값이 0.03만 달랐기 때문에 어느 값을 정답으로 볼 수 있는지는 데이터만으로 확정할 수 없었음. 다만 같은 시간에 같은 설비를 검사한 기록을 두 번 반영하는 것보다는 한 행만 남기는 것이 안전하다고 판단하여 **먼저 나온 행을 유지**함.
* **이상값 처리 방식 결정:** 이상값을 행째 삭제할지, 상한·하한으로 제한할지, 대표값으로 바꿀지도 정답이 하나로 정해져 있지 않았음. 이번 데이터에서는 C라인 3행이 사라지는 문제를 확인했으므로 **행 수를 보존**하는 방향을 선택했고, 평균보다 극단값의 영향을 덜 받는 **생산라인별 중앙값**으로 압력 이상값을 대체함.
* **신규 생산라인(Unseen Line) 처리:** 새 배치에 기존에 없던 생산라인이 포함된 경우에는 기존 A·B·C라인의 규칙을 임의로 적용하지 않음. 기존 라인 매핑에 없는 값은 라인코드가 결측값이 되므로 새 라인 데이터를 따로 분리하고, 기준을 추가로 정한 뒤 처리해야 한다고 판단함.

## 4. 멘티에게 전할 한 가지 핵심 조언

> **"다음에 같은 데이터를 받으면 가장 먼저 행 수와 업무상 고유키의 중복 여부를 확인해야 합니다."**

* 단순히 `drop_duplicates()`만 실행하면 센서값이 조금 다른 중복 기록은 남을 수 있음. 따라서 전체 행 수와 생산라인별 행 수를 비교하고, `검사일시`, `생산라인`, `설비번호` 조합이 실제로 한 행씩만 존재하는지 먼저 확인한 뒤 이상값·결측값·정규화를 처리해야 함.
