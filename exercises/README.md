# 데이터 정제 · 전처리 실습 (멘토 · 멘티)

pandas로 지저분한 데이터를 분석 가능한 상태로 만드는 실습 과제 모음입니다.
날짜별로 한 세트씩 들어 있고, 각 세트는 **멘티**(따라 하며 배우기)와 **멘토**(제대로 된 방법으로 처리·검수) 두 트랙으로 나뉩니다.

## 폴더 구조

```
YYYY-MM-DD/
├── 멘티/   멘티과제.py + 데이터 (10문제, 자가채점)
└── 멘토/   멘토과제.py + 데이터 (5문제, 라인/구역별 기준·검수)
```

> 정답과 채점 스크립트는 공개하지 않습니다.

## 준비물

```bash
python3 -m pip install pandas numpy
```

## 하는 법

1. 원하는 날짜 폴더로 들어갑니다.
2. **멘티**: `멘티/멘티과제.py`를 열고 문제 1번부터 순서대로 풉니다. 각 문제에 **기대 출력**이 적혀 있으니 스스로 채점하세요. 숫자가 다르면 앞 문제로 돌아가 확인합니다.
3. **멘토**: `멘토/멘토과제.py`를 풉니다. 멘티와 같은 원본을 더 제대로 된 방법(그룹별 기준, 순서, 반복, 자동화)으로 처리합니다.
4. 데이터 파일(csv)은 과제 파일과 같은 폴더에 있으니 그대로 실행하면 됩니다.
